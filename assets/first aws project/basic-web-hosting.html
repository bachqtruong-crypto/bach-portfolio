My First AWS Project

Hosting a Simple Page with S3 and CloudFront

Home About Projects

Overview

For my first AWS project, I wanted to start with something simple but still useful. The goal was to host a basic web page using an S3 bucket and then deliver it through CloudFront.

This is a very common real-world setup for static websites, making it a great starting point for learning AWS fundamentals.

Architecture Diagram

Step 1: Create an S3 Bucket

The first thing I did was create an S3 bucket. Inside the AWS console, I navigated to:

S3 → Create Bucket

I named my bucket bach-bucket67. Bucket names must be globally unique, so you may need to try a few variations.

I kept most settings as default. Importantly, the bucket starts as private, which is the recommended security practice.

Step 2: Create a Simple HTML Page

Next, I created a simple HTML file using Notepad and saved it as index.html. 

<!DOCTYPE html>
<html>
<head>
    <title>My First AWS Project</title>
</head>
<body>
    <h1>Hello, this is my first AWS project!</h1>
</body>
</html>

Nothing fancy—just enough to confirm everything works.

Step 3: Upload the File to S3

I uploaded the file to my bucket:

  • Open bucket (bach-bucket67)
  • Click Upload
  • Select index.html
  • Upload

The file is now stored in S3, but since the bucket is private, it cannot be accessed publicly. This is where CloudFront comes in.

Step 4: Create a CloudFront Distribution

Instead of making the bucket public, I used CloudFront to securely deliver the content.

CloudFront → Create Distribution

  • Origin: S3 bucket (bach-bucket67)
  • Enabled Origin Access Control (OAC)
  • Left other settings as default

Setting the Default Root Object

This is a critical step:

  • Go to your distribution
  • Edit settings
  • Set Default Root Object to: index.html

Without this, CloudFront may return an AccessDenied error because it doesn't know which file to display.

After saving, I waited a few minutes for deployment.

Step 5: Test the Website

Once deployed, CloudFront provided a domain like: 

d123abcd.cloudfront.net

Opening that URL showed:

"Hello, this is my first AWS project!"

Why This Setup Matters

Even though this is a simple project, it introduces several important AWS concepts:

  • S3 for static website storage
  • CloudFront for global content delivery
  • Private buckets for security
  • Origin Access Control (OAC)

This architecture is very similar to what many production static websites use.
